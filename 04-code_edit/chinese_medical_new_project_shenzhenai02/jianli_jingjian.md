# 项目经验

## 中医药知识图谱智能问答系统

### 项目背景
中医药知识体系庞大复杂，传统检索方式难以满足专业查询需求。本项目旨在构建一个基于知识图谱的智能问答系统，通过整合现代AI技术与传统中医药知识，为用户提供精准、高效的中医药知识查询和解答服务。

### 技术栈
- **后端框架**：FastAPI
- **前端框架**：Streamlit
- **知识图谱**：Neo4j + Cypher
- **向量检索**：FAISS
- **工作流引擎**：LangGraph
- **大语言模型**：LangChain + OpenAI API
- **数据爬取**：BeautifulSoup + Requests
- **向量嵌入**：Sentence-Transformers

### 我的职责
1. **数据采集与处理**
   - 设计并实现中医药网站爬虫系统，采集数千种中药和方剂的详细信息
   - 开发数据清洗和结构化处理流程，确保数据质量和一致性

2. **知识图谱构建**
   - 设计中医药领域知识图谱模型，定义中药、方剂、功效等实体及关系
   - 实现批量数据导入Neo4j，优化导入性能，处理数据冲突
   - 构建FAISS向量索引，实现基于语义的实体匹配

3. **智能问答系统开发**
   - 基于LangGraph构建8节点工作流，实现意图识别、实体提取、图谱查询和答案生成
   - 设计动态Cypher查询生成机制，根据问题类型自动生成图数据库查询语句
   - 实现查询检查和优化模块，确保系统安全性和响应效率

4. **Web应用开发**
   - 使用FastAPI构建高性能API服务，处理并发请求
   - 使用Streamlit开发用户友好的Web界面，实现实时交互

### 项目成果
- 构建了包含数千种中药和方剂的中医药知识图谱
- 实现了准确率超过85%的智能问答系统，支持复杂中医药问题解答
- 开发了完整的Web应用，提供直观的用户交互体验
- 系统响应时间控制在2秒内，支持并发用户访问
- 创新性地结合知识图谱和大语言模型，提高了问答系统的准确性和可解释性
